Данная программа разработана для алгоритма поразрядной сортировки (версия MSD). Она работает только с целыми числами, имеет функцию сохранения в файл. При заполнении массива данными перед пользователем выдаются четыре способа заполнения: самостоятельно, рандомными числами в диапазоне и без, из файла. Также предусмотрены сообщения об ошибoчном вводе.
